# Bandit-OverTheWire

A curated repository that collects resources for the Bandit wargame from OverTheWire. This repo contains a beginner-friendly PDF walkthrough covering Bandit levels 0 through 15 plus supporting projects.

## Contents
- A Beginner's Walkthrough — Level 0 to Level 15 (1).pdf — A beginner walkthrough (step-by-step with screenshots) covering Bandit levels 0–15.
- README.md — This file.
- PDF_SUMMARY.md — A short extracted summary of the included PDF.

## Quick start
1. Clone the repository:

   ```bash
   git clone https://github.com/janavikaprabath/Bandit-OverTheWire.git
   cd Bandit-OverTheWire
   ```

2. Open the walkthrough PDF in your preferred PDF viewer:

   https://github.com/janavikaprabath/Bandit-OverTheWire/blob/main/A%20Beginner's%20Walkthrough%20%E2%80%94%20Level%200%20to%20Level%2015%20(1).pdf

3. Read the PDF for step-by-step guidance on Bandit levels 0–15. See `PDF_SUMMARY.md` for a brief summary of the document.
